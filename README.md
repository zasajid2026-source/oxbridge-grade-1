# Oxbridge World-Wide Science — Grade 1 (Check Site)

Oxbridge World-Wide Science Grade 1 — check site (posters + day tools).

Static, phone-friendly: open `index.html`. 8 units, 50 topics; each topic shows its style-v2 poster (WebP) and links to its Worksheet, Lesson Plan and Key Points pages. The Visual Explainer button opens the topic's own poster full-size (the explainer is the poster itself). Worksheets are unsolved (no answers shown); Key Points use the colourful visual-notes style in Oxbridge Emerald & Gold. No login, no build step — publish the folder as-is (e.g. GitHub Pages).
